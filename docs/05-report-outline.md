# CA-3 Case Study Report Outline

Follow the sequence specified in the CA-3 guidelines. Replace every bracketed prompt with findings from your group's actual investigation.

## Title Page
Use the faculty-provided title-page format. Fill in project title, department, all group members' full names and roll numbers, faculty guide, institute and academic year.

## 1. Introduction
- Open-source software context relevant to this case study.
- Objective and scope of the investigation.
- What the group actually performed.

## 2. Project Overview
- ESPHome's purpose, functionality, key features and problem addressed.
- Cite official project sources.

## 3. Repository Investigation
- Official repository and structure.
- Source code, documentation, tests and project activity explored.
- Include labelled screenshots.

## 4. Issue Investigation
- Issue #16254: reported problem, discussion, status and linked PR.
- Distinguish reporter statements from group findings.

## 5. Bug Investigation
- Environment, exact reproduction steps, expected and actual results.
- Logs/screenshots and outcome.
- If not reproduced, document the attempt and reason/result.

## 6. Contribution Process
- Project contribution guidelines, setup, tests, code review and PR workflow.
- Cite the exact official documents inspected.

## 7. Pull Request Investigation
- PR #16273: purpose, changed files, implementation, tests, review and status.
- Explain the change rather than only showing screenshots.

## 8. Practical Observations
- Commands run, configurations used, test results, limitations and lessons.

## 9. Changes / Contribution
- Describe only work performed by your group.
- Include files changed, tests and Git history/PR evidence.
- If no code contribution was completed, state this honestly and explain what was investigated.

## 10. Conclusion
- Findings, what the group learned, limitations and possible future work.

## 11. References
- List repository, issue, PR, official documentation and any other sources actually used.
- Include titles and access dates where appropriate.
