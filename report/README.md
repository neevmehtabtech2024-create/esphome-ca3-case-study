# Report assembly

Use `docs/05-report-outline.md` as the structure and transfer the researched content from the other documents into the prescribed course template.

Before submission:
- Replace all group placeholders.
- Add genuine screenshots and local test output, or explicitly state that local reproduction was not completed.
- Check the course's exact title-page and formatting requirements.
- Add in-text citations/URLs for the issue, PR, repository, and official developer documentation.
- Ensure all group members can explain the issue and fix.
- Do not claim authorship of the upstream PR.
